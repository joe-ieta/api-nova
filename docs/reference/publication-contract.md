# 资产、发布与样例合同

本文件合并原资产模型、端点语义、发布资源及二进制样例说明，描述当前既有合同。功能状态以[统一台账](../guides/active-work-package-execution-status.md)为准，原批准条款和阶段证据在[归档](../archive/README.md)保留；归档不撤销未完成任务的原退出条件。

## 资产和运行身份

| 对象 | 含义 | 不得混同 |
| --- | --- | --- |
| 源服务资产 | 逻辑API来源及端点集合 | 不将某次运行地址作为不可变化的资产身份 |
| 端点定义 | 方法、规范路径、语义和治理入口 | 不等同于已部署路由或MCP工具 |
| 源服务运行实例 | 实际base URL、环境和关联配置 | 无servers的导入可以没有实例 |
| 运行资产 | 面向消费者的Gateway或MCP集合身份 | 不等同于单个端点或一次进程PID |
| 运行成员 | 运行资产纳入的具体端点及profile/route | 成员就绪和已发布状态需分别检查 |
| 成员上游绑定 | 当前环境实际选择的运行实例 | 不能继续使用已归档实例或陈旧绑定证据 |

运行资产、成员、实例及端点关系由API持久化。自定义UI通过管理API操作，不直接修改数据库或把UI缓存当作当前准入事实。

## 测试、治理、验证和激活

注册只入目录；测试形成调用/样例证据；治理决定候选资格；发布成员和部署运行资产形成消费者可调用入口。状态变化及证据失效由服务执行，不靠客户端写一个ready标志绕过。

候选验证绑定实际成员、绑定、配置和revision；改变上游或治理条件后应使用新证据。失败候选保留旧发布状态；部署成功、监听成功、消费成功分别核对。完整跨进程/多主机首次激活CAS仍属于未批准的强化范围，原PROD-06核定保留。

批量成员发布允许逐成员提交，任一成员失败则阻止整Runtime自动部署。已成功成员的新发布修订不等于在线部署修订；在线请求继续使用已验证快照，并核对当前成员/发布绑定的一致性与服务端事务记录的修订连续性。部分失败和重复发布不得仅因修订向前导致旧路由503；修订回退、记录错配、成员禁用/下线及当前策略或认证变化仍须在缓存前拒绝。下线会切断连续性，之后仅重新发布而未部署不能复活被撤销的旧部署；连续性记录不是权限、凭据或新候选激活许可。

入口与字段见[API手册](../api/README.md)、[接口清单](../api/ENDPOINTS.md)和对应DTO，不复制另一套易漂移JSON字段表。

## MCP发布端点

受管MCP部署使用已有transport、port、endpointPath及入站认证配置；目前受管HTTP传输为streamable/sse，独立CLI另支持stdio。endpoint预览与实际部署采用同一参数，但预览/端口预检不持有socket租约，不保证稍后bind成功。

有效监听地址、CLI参数和mcpConfig应一致；失败不能悄悄改端口仍返回旧预览地址。autoStart=false时保存不表示进程已监听。端点/认证变化纳入候选和运行指纹，旧证据不能跨配置复用。

## 消费凭据与上游迁移

管理JWT控制资产和凭据操作；运行时消费凭据约束Gateway/MCP调用。凭据范围、工具范围、过期和撤销依赖当前运行状态；完整秘密按创建接口一次性交付方式处理，读取配置不保证重新返回原秘密。

实例A下线迁移B时保留逻辑资产与成员身份，更新实例、绑定和测试/验证证据。迁移并不等于自动修改消费者认证或跳过治理。

## 二进制样例与留存

普通样例采用现有大小、脱敏和留存规则；二进制走单独受控对象根和描述符，不和统一可观测正文目录、配额或GC混用。当前本机Windows/PG/HTTP留存流程已有PROD-04C限定证据，目标运行账户ACL、Linux文件语义及MCP真实二进制外发仍开放。

- 列表/运行记录不内联原始二进制；样例持受控不透明对象引用，未就绪或staged对象不可读。
- 下载通过`GET /api/v1/endpoint-testing/test-samples/{sampleId}/binary-content`，要求server:manage及当前归属/对象/样例状态检查；固定attachment/octet-stream、nosniff、no-store，不支持Range。
- 归档不等于立即撤销；删除/到期整理先撤销引用，再有界清理对象。失败保留delete_pending/墓碑，不能称已回收或自动重试成功。
- 显式对象整理受server:manage保护，沿用至少5分钟宽限、最多100对象和开始下个对象前的2秒软预算；单次文件操作不保证2秒内结束。
- 当前二进制描述符仅显式status-only候选回放可按已有门禁继续；binary-exact及未知模式/版本不支持。物理对象失效也应阻断候选并保旧。
- 清理开关/路径、安全围栏和业务库归属不能靠前端参数绕过；本轮未默认启用生产对象存储或后台对象清理。
