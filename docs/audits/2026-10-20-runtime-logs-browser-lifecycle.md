# 真实运行事件日志与无 server、多端点、A/B 迁移浏览器补验

## 本轮范围

基于 `oc_dev / 0d7f203`，按用户确认的顺序推进日志页真实数据、人工测试准备和浏览器覆盖。所有联合测试使用独立 SQLite 数据库、临时端口及本机 A/B 上游；不使用历史业务数据库。

本轮修改属于 rc.4 之后的开发分支，未修改或重新发布 v1.7.6-rc.4，不把新修复记为该预发布包已有能力。历史任务仍为 209 条：204 DONE、2 IN_PROGRESS、1 WAIT_DEP、2 DEFERRED。

## 修复与数据边界

1. 日志页删除六条硬编码示例，接入已有、受 `monitoring:read` 保护的 `/api/v1/monitoring/management/events`。每页最多 50 条，级别筛选在服务端执行，搜索及来源筛选仅作用于当前页；界面明确显示这一范围。摘要为空时显示持久化的事件名称，时间和身份均来自服务器。这里显示运行事件，不替代进程日志文件或完整安全审计。
2. 加入加载、无权限、失败、超时、格式异常与真实空结果状态。失败清除旧记录；刷新保留筛选；顶部刷新等待当前日志查询。退出登录、换令牌、清空和卸载取消旧请求并丢弃迟到结果。“清空当前显示”不调用删除接口、不删除服务器数据。
3. 浏览器发现 URL 导入无 `servers` 的文档会经过解析器的兼容默认值补入 `http://localhost`，保存后误创建实例。管理端解析链现在启用 `preserveMissingServers`，保留缺省/空 server；解析器其他调用方的原兼容默认行为不变，显式 localhost、相对 server 和 Swagger 2 转换保持有效。
4. 实例编辑框调整端口及优先级输入宽度，解决端口输入区被挤没而无法操作的问题。
5. 首次打开 production 环境的运行绑定时，正确识别 HTTP 适配器标准化后的 404；“尚无绑定”进入正常创建流程并显示已有实例。加载开始清除前一个绑定的候选列表。

## 验证记录

- API 最终完整回归：186 suites / 1950 tests 全部通过；解析器 51 suites / 1213 tests 通过，含新增服务器保留策略 6 项。
- UI 脚本回归 95/95，其中新增日志专项 6 项，覆盖认证请求、分页/级别映射、可空摘要、异常响应、超时、旧请求竞态和会话清理。API、解析器及 UI 生产构建通过；生产文案专项 2150 条通过。
- 打包 UI 无 server URL 导入、双端点、A/B 迁移及日志：37/37，`.tmp/ops-01-browser-OwGDBf/evidence.json`。真实运行事件总数 205，显示首批 50 条；两个端点的 B 实例回放结果、绑定修订及身份均回读验证。
- Vite 带 server 文件导入和日志回归：22/22，`.tmp/ops-01-browser-yosxap/evidence.json`，真实事件 87 条。两轮均无浏览器未捕获错误，所有测试端口清理完成。
- 本机 lint：0 error、273 warnings（API127、parser68、UI78），保留原有技术债。本轮没有重新执行依赖公告审计，不把 rc.4 的审计记录改写为新结果。

浏览器业务变更均由可见 UI 操作；管理 API 只作结果回读。受控上游 Registry 的加载属于测试环境装配；消费者用真实 HTTP 发起请求。日志错误、空页、分页及恶意文本的受控响应单独标记，不能作为真实后端权限或持久化证据。

浏览器流程验证：无 server URL 导入两个端点且不创建实例 → 显式配置 A → 探测、测试和准入 → 同一 Gateway/服务前缀发布两个端点 → 页面创建消费凭证 → 未认证拒绝、认证成功、访问日志与监控终态 → 归档并停止 A → 配置 B → 保持文档、来源、端点、成员身份，重新绑定和部署 → 持久化验证记录锁定 B，两个入口实际返回 B。日志页另对照真实持久化事件、清空后服务器记录不变及顶部刷新恢复。

首轮发现和修复保留在 `.tmp/ops-01-browser-*/evidence.json`：无 server 被填为 localhost（lWzdDV）、端口输入不可操作（zulGOc）、production 首次绑定 404 处理错误（g37BPc）。日志首次联调发现合法事件摘要可为空（iruc7U），已支持事件名回退。脚本调试阶段还修正了测试结果显示范围、表格点击位置和确认按钮语言匹配；API 首轮新增参数化测试类型错误修正后，最终完整 186 套通过。失败轮次不计为通过。

证据记录当时父提交 `0d7f203`、工作树、关键源码/构建哈希、Node/Edge 版本、独立数据库路径及清理状态。37 阶段通过后，审查又收紧了日志未知级别校验，拒绝 `constructor` 等继承属性名；新增畸形响应断言并重新运行 UI 回归和构建，最终打包 UI 文件导入/日志回归 22/22：`.tmp/ops-01-browser-WvWFvx/evidence.json`，无浏览器未捕获错误且端口全部清理。没有借此改变有效事件、解析器或迁移逻辑。

| 人工检查 | 预期与记录要求 |
| --- | --- |
| 登录、顶部健康及刷新 | 对照真实 `/health`；记录平台、构建版本、5GiB 空闲门槛及 MCP 状态 |

| 两端点同一 Gateway | 两条入口共用服务前缀；无凭证拒绝、有效凭证返回预期业务结果 |
| A/B 更换 | 保留文档与端点身份；旧实例归档后，新实例探测/测试/部署并可消费 |
