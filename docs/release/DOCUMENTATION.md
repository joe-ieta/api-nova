# 文档整理与随包交付

本套文档面向当前开发分支，当前交付候选仍为v1.7.6-rc.5。本轮没有发布新版本、改旧tag/产物或访问生产。原批准退出条件、209项任务及245条依赖不变；生产签收、人工反馈和延期继续保留。

## 当前手册与归档

定位/设计/使用/部署/开发API分工见[阅读入口](../README.md)，全部现行文档和类型见[清单](../VERSIONS.md)。重复的资产/发布/样例说明合为发布合同；安全/凭据/网络/邮件合为安全合同；调用/配额/留存合为可观测性合同，接口细节留在对应API手册。

历史审计、阶段计划/状态、旧交接、教育性通用说明、过期Parser技术方案及rc.2/rc.3/rc.4版本说明进入[归档](../archive/README.md)。归档保留正文、日期、原审批及证据，只修引用；旧front-matter的active不表示仍是现行手册。当前rc.5版本说明和包内文档不重写，新增手册用于下一次新版本交付。

## 可重复维护

```bash
node scripts/refresh-doc-catalog.cjs
node scripts/verify-docs.cjs
node scripts/export-api-docs.cjs --check
```

控制器/DTO变化先构建并执行export-api-docs.cjs生成快照，再检查；普通文档修改无需重复全部业务测试。校验器覆盖全仓文档（含归档）本地文件和Markdown锚点、清单/元数据，以及任务合同/依赖。生成器额外在隔离SQLite、随机身份和回环临时端口实际执行登录、目录读取、匿名拒绝及刷新示例。

当前快照为227路径、267操作、232个schema；它描述Swagger可见控制器，动态Gateway/MCP/Socket.IO和注解缺口在[API手册](../api/README.md#接口清单与快照边界)说明。Parser最小例子也已实际运行。测试结果不外推生产安全、SMTP/Webhook或未验矩阵。

## 文档随包交付

从干净已提交的精确发布源执行正常打包时，package-release.ps1会调用export-release-docs.cjs，将现行清单中的手册、当前版本记录和API JSON写入docs/及对应相对位置。历史/源码/模板链接固定到同一源commit的GitHub页面；主手册间离线可读，在线追溯需要网络。

可独立导出到**全新**预览目录核对，不需要重建运行时：

```bash
node scripts/export-release-docs.cjs --output-dir .tmp/documentation-preview-new
```

导出拒绝覆盖现存目标文档，不修改已有运行数据；DOCUMENTATION_MANIFEST.json记录文件摘要、源commit和本地链接检查。脏工作区只用于预览，正式发布仍要求干净同步提交、三平台同源和全部发布门禁。预览不宣称已发布或三平台包已通过新验证。

归档移动前后路径和原始摘要在[映射](../archive/relocations-2026-10-26.json)保留，原不同日期的统计只在对应记录内解释；当前唯一任务计数仍为209。未随仓库保留的旧材料会明确标记历史引用缺失，不伪造文件或复原证据。
