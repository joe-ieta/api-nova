# ApiNova v1.7.5-rc.2

> 发布状态：`prerelease`
> Git 提交：`@GIT_COMMIT@`
> 发布日期：`2026-09-04`
> 上一版本：`v1.7.5-rc.1`

## 核心变化

- 建立项目顶层统一发布规范，固定 Windows x64、Linux x64 和 Linux ARM64 三平台离线产物契约。
- 新增三平台原生构建、包级冒烟、归档解压复验和校验记录流水线。
- 恢复 API、Parser、UI 的 lint 发布门禁，改为无磁盘副作用检查并清除现有 error。
- 固定不可变版本归档、latest 三平台运行目录、版本说明和快速运行手册结构。
- 离线启动脚本不再尝试安装依赖，并支持 CI 使用无浏览器模式验证同一启动入口。
- 修复干净检出环境中 UI 日志模块被忽略、导致生产构建失败的问题。

## 已修复问题

- 阻止打包脚本直接重建 `api-nova-release` latest 目录，避免误删运行数据。
- 消除历史发布中只提供 Windows 包、平台命名不统一和首次运行可能联网的差异。
- 修复发布门禁的构建顺序，使 Server CLI 产物在 API runtime closure 检查前生成。

## 兼容性与配置

- API 兼容：业务 API 相对 `v1.7.5-rc.1` 无代码变化。
- UI 行为：业务 UI 相对 `v1.7.5-rc.1` 无代码变化。
- 运行时/配置变化：正式包内置 Node.js `v24.15.0` 和目标平台生产依赖。
- 安全影响：包内仅包含公开的本地测试默认账号和默认 JWT 密钥；接入共享网络前必须修改 `.env`。
- 数据兼容或迁移：不提供历史数据迁移；晋升 latest 时旧运行数据可丢弃。
