# 项目概览、能力定位与功能范围

ApiNova（达雅）把已有HTTP API整理成可治理、可测试、可发布的能力资产，面向普通应用提供HTTP Gateway，面向模型和Agent提供MCP Tools。适用于应用内部的API能力交付；现有业务系统和上游API仍负责业务数据及业务规则。

当前已交付候选为 **v1.7.6-rc.5**，属于人工测试预发布；生产签收尚未完成。本套文档整理的是当前开发分支已有能力，不代表旧发布包内的说明文件已被替换。

## 产品主线

1. **注册**：从OpenAPI/Swagger URL、文件、文本导入，或手工登记端点。
2. **测试**：选择实际运行实例，探测并执行端点测试，保留运行及受控样例。
3. **治理**：查看就绪条件、认证及测试证据，明确端点可发布性。
4. **发布**：将合格端点装配为Gateway或MCP运行资产，配置成员、上游绑定和消费权限。
5. **运行与观察**：执行候选验证、部署、启停、凭据管理，按资产关联调用、事件、日志和监控。

注册成功不等于已经发布；保存配置不等于已启动；进程存活不等于上游业务可调用。

## 已有能力及适用边界

| 能力 | 当前可用路径 | 边界 |
| --- | --- | --- |
| 规范处理 | OpenAPI/Swagger解析、校验、归一化、Swagger2兼容转换 | Parser负责统一语义；导入不自动提供真实运行地址或业务认证 |
| 资产与运行实例 | 源服务、端点、运行资产分层；显式实例和成员上游绑定 | 无servers的导入可保留未绑定；实例A/B迁移不必重新导入 |
| 测试与发布准入 | 端点探测、测试用例/运行/样例、治理、候选重放与失败保旧 | 准入、环境、权限、实际绑定需满足；不能任意跳过验证 |
| HTTP Gateway | 已发布成员路由、消费凭据、受控转发、访问日志 | 产品内API发布入口；不是企业全部流量网关 |
| MCP | 工具生成；stdio、streamable、sse；受管进程和凭据撤销 | 独立CLI与产品受管发布配置不同；管理WebSocket不是MCP transport |
| 管理安全 | 管理JWT、角色/权限/资源范围、运行时独立消费身份、上游凭据隔离 | host/许可/受管IPC等能力按部署合同显式装配，代码存在不表示默认全开 |
| 可观测性 | 调用事实/正文/统计/事件、Socket.IO事件与状态订阅、Outbox/Webhook、保留及配额 | worker默认关闭；全局实时性、真实业务存活、实际收件和生产容量不能由局部证据推定 |
| 运维与邮件 | 进程/日志/健康、受控sink及SMTP邮件流程、SQLite/PostgreSQL | 实际SMTP/Webhook、目标账户ACL、TLS/代理和恢复回退仍需目标签收 |
| 交付 | Windows x64、Linux x64、Linux ARM64原生离线包 | rc.5 Linux在Ubuntu24.04验收；安装包与目标环境支持矩阵分别说明 |

## 明确保留的限制

- 正式台账共209项：204 DONE、2 IN_PROGRESS、1 WAIT_DEP、2 DEFERRED；任务大小不同，不计算产品完成率。
- SEC-F4-02、OBS-16-04和OPS-01的安全、运维及生产签收仍开放；自动化通过不能代替用户人工反馈。
- 2026-10-26依赖审计命中7个high、9个moderate包节点；风险处置归SEC-F4-02，不能沿用发布时的0 high结论。
- SQLite3000样本未完成全量观察，保留为非阻断诊断，不承诺相应生产容量；数据完整性、权限、持久化和恢复要求保留。
- OAuth2、额外令牌适配、跨协议QoS继续延期；独立UI发行、新SDK、SSO及完整跨进程CAS不在本轮范围。
