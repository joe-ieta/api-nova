# 使用手册：注册到发布与消费

使用前按[部署手册](DEPLOYMENT.md)启动，登录管理界面。本文描述现有工作流；当前测试候选及签收边界见[项目概览](../overview/PRODUCT.md)。

## 1. 注册与运行实例

从URL、文件或原始文本导入OpenAPI/Swagger，或在注册界面手工登记端点。检查规范解析结果、端点方法/路径、所属源资产。

文档没有servers时，可以登记端点而不自动创建运行实例。进入源服务的运行实例配置，显式填写实际地址及必要认证，再进行探测。不要用重新导入替代运行实例维护。

## 2. 测试与治理

选择正确实例，执行探测及端点测试，检查HTTP状态、响应和测试运行证据。维护样例的启用、归档和保留状态。进入治理查看就绪条件；受限或缺证端点应先解决具体原因。

二进制样例需要受控存储开关和权限；列表不内联原始字节。当前无binary-exact回放能力，只有符合合同的status-only路径。详见[样例合同](../reference/publication-contract.md#二进制样例与留存)。

## 3. 装配发布资产

在发布工作台选择合格端点，创建Gateway或MCP运行资产及成员，配置成员发布profile和显式上游绑定。一个Gateway可包含多个端点。

Gateway成员配置路由；MCP成员配置工具及端点参数。预览、保存、验证、激活、启动是不同动作：按界面返回的门禁完成候选验证，检查失败原因；不能凭保存成功判断消费可用。

MCP监听按实际transport、port和endpointPath确认，默认HTTP路径`/mcp`，SSE默认`/sse`；以API返回的有效地址为准。stdio用于进程标准输入输出，不能当作HTTP URL访问。

## 4. 消费与观察

按运行资产配置创建消费凭据，并将完整凭据交付给获准的客户端。管理JWT不能代替Gateway/MCP消费凭据，消费凭据也不应作为上游认证秘密。

执行一次无凭据请求，确认受到拒绝；再用有效凭据执行已发布端点。在资产访问日志、调用事实及监控中关联同一requestId/trace/invocation。不同日志来源的范围不同；日志页的搜索和来源筛选只作用于当前50条页，不是全量日志检索。

MCP客户端连接现有工具端点，完成工具列举及调用；协议与配置见[MCP手册](../api/mcp.md)。

## 5. 上游迁移与回退

在隔离测试或获准环境中维护实例B，显式重新绑定、测试、验证并部署后再归档/下线A。核对逻辑资产、端点、成员身份和消费地址，确认请求到达B。不要删除源资产来完成地址迁移。

候选验证失败应检查旧版本仍在服务；实际回退还需原发布配置、完整数据备份及目标环境证据。禁止直接覆盖不可变发布归档。

## 6. 人工测试与反馈

当前rc.6人工操作顺序以[版本快速指南](../release/versions/v1.7.6-rc.6/QUICK_START.md)为准。记录平台/CPU、版本/commit、前置配置、操作、预期与实际、脱敏请求ID/日志；生产签收和未验角色/认证/MCP浏览器组合继续保留在[open-items](../reference/open-items.md)。自动浏览器结果不代签人工反馈。
